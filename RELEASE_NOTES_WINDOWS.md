# MOV2MP4 v0.1.0 — Windows Release

A simple, fast tool for turning MOV files into MP4 locally on your Windows PC.

Made for editors, creators, and anyone who wants their videos converted without dealing with file limits, cloud uploads, or complicated settings.

---

## Download

Download:

**MOV2MP4-Setup.exe**

*Works on Windows 10 and Windows 11 (64-bit).*

---

## First time setup

You don't need to install Python, FFmpeg, Command Prompt tools, or pip packages. Everything is bundled into a single installer.

### 1. Download the installer

Download **`MOV2MP4-Setup.exe`**.

### 2. Run the installer

Double-click **`MOV2MP4-Setup.exe`** and follow the steps.

### 3. Open MOV2MP4

Open **MOV2MP4** from your **Start Menu** or **Desktop** shortcut.

---

## ⚠️ If Windows blocks the installer (SmartScreen)

Because this is an early project and not digitally signed yet, Windows Defender SmartScreen might show a warning ("Unknown publisher").

If that happens:

1. Click **More info**.
2. Click **Run anyway**.

---

## Using MOV2MP4

Once the app opens:

### Add your videos

Drag your `.mov` files or folders directly into the app.

You can add multiple files at once.

### Choose where the MP4s go

Click **Browse Folder** to select where you want your converted videos saved.

### Convert

Click **Start Conversion**.

That's it.

Your MOV files stay on your PC. Nothing is ever uploaded anywhere.

---

## Useful options

- **Batch conversion** — Convert multiple videos at once.
- **Output Folder** — Save converted MP4s anywhere you choose.
- **Overwrite existing files** — Re-convert and overwrite existing MP4 files if needed.
- **Delete Original** — Automatically remove source MOV files after successful conversion. *(Be careful with this setting! Only turn it on if you actually want the original MOV files removed.)*
- **Cancel anytime** — Stop active conversions safely without corrupting files.
