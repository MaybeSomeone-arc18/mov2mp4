# MOV2MP4 v0.1.0 — macOS Preview

A small tool for turning MOV files into MP4.

Made mainly for editors and people who just want their videos converted without dealing with a bunch of stuff.

## Download

Download:

**MOV2MP4-macOS-arm64.dmg**

This works on Apple Silicon Macs:
M1, M2, M3, M4 and newer.

---

## First time setup

macOS is going to make this slightly annoying.

I haven't paid for Apple's developer program yet, so the app isn't verified by Apple.

Don't worry — you don't need to install Python, FFmpeg, Homebrew or anything else.

### 1. Download the DMG

Open the downloaded `.dmg` file.

### 2. Move MOV2MP4 to Applications

You'll see MOV2MP4 in the window.

Drag it into **Applications**.

### 3. Try opening MOV2MP4

Go to:

**Applications → MOV2MP4**

and open it.

If it opens, you're done. 🎉

### If macOS blocks it

If you get a message saying macOS can't open or verify MOV2MP4:

Go to:

**System Settings → Privacy & Security**

Scroll down until you see the message about MOV2MP4 being blocked.

Click:

**Open Anyway → Open**

Then try opening MOV2MP4 again.

### Still not opening?

There's a small helper included in the download called:

**Launch MOV2MP4**

Open the original DMG again and double-click it.

If macOS blocks the launcher too:

**System Settings → Privacy & Security → Open Anyway**

Then open **Launch MOV2MP4** again.

It will handle the annoying macOS security part and start MOV2MP4 for you.

You should only have to do this once.

---

## Using MOV2MP4

Once the app opens:

### Add your videos

Drag your `.mov` files into the app.

You can add multiple files at once.

### Choose where the MP4s go

Before converting, choose the folder where you want the converted videos to be saved.

### Convert

Click **Start Conversion**.

That's it.

Your MOV files stay on your Mac. Nothing is uploaded.

---

## A few useful options

You can also:

- convert multiple videos at once
- cancel a conversion
- overwrite an existing MP4
- delete the original MOV after a successful conversion

Be careful with **Delete Original** — only turn it on if you actually want the original MOV files removed.
