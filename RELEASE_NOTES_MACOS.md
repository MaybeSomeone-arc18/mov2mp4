# MOV2MP4 v0.1.0 — macOS Preview

A simple batch MOV → MP4 converter for creators and editors.

Features:
- Drag & drop
- Batch conversion
- Conversion queue
- Per-file status
- Cancellation
- Custom output location
- Optional overwrite
- Optional delete-original
- Local FFmpeg processing
- No Python installation required
- No separate FFmpeg installation required
- Includes "Launch MOV2MP4" launcher fallback for macOS Gatekeeper/quarantine issues

Platform:

macOS Apple Silicon / arm64

Status:

Early public preview.

Windows support is being packaged and tested separately.
