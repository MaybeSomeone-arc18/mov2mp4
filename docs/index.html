Features

Built for your
workflow.

Engineered for utility. Rapid execution where it matters, private by default.

Batch processing

Process individual clips or entire directories simultaneously with optimized multithreading.

Fully offline

Zero data telemetry. Files remain entirely on your local storage and never touch a network.

Targeted output

Define exact destination paths. Choose to overwrite existing files or save alongside original sources.

Safe cancellation

Interrupt active processes safely without corrupting partial outputs or leaving broken files behind.

Automated cleanup

Configure automated deletion of source files post-conversion to preserve disk capacity.

Zero dependencies

A standalone binary with bundled FFmpeg. No terminal commands or package managers required.
